# NetNote Group – Email Templates

Professional, mobile-friendly HTML email templates for **NetNote Group** and its three companies. Each template has a branded header, message area, call-to-action button, company description, contact details and social links.

## Templates

| File | Use for |
|------|---------|
| `netnote-group-email.html` | General, partnership and government emails |
| `netnote-systems-email.html` | Networking, IT support, websites, software and cloud clients |
| `netnote-security-email.html` | CCTV, access control and cybersecurity clients |
| `netnote-aero-email.html` | Drone and robotics clients |

Logos: `netnote-group-logo.jpg`, `netnote-systems-logo.jpg`, `netnote-security-logo.jpg`, `netnote-aero-logo.jpg`

## Features

- Email-safe HTML (tables and inline styles) that works in Gmail, Outlook and phone apps
- Responsive layout that adapts to small screens
- Pre-filled WhatsApp button for each company
- Light inbox preview text
- Same design across all four templates

## Before you use them

Edit the placeholders in square brackets and these links:

- `[Client name]`, `[Date]`, the message text and `[Office address, Town, Kenya]`
- `https://YOUR-SITE-URL/images/logos/...`: the web address where the logo is hosted (email apps cannot show images stored in a file)
- `https://YOUR-PORTFOLIO-URL`: your website link

## How to use in Gmail

1. Open the HTML file in a browser, press `Ctrl+A`, then `Ctrl+C`.
2. In Gmail, click **Compose** and paste.
3. Three dots → **Templates** → **Save draft as template**.
4. Next time: **Compose** → three dots → **Templates** → pick the template, edit the text and send.

Turn on Templates first in Settings → See all settings → Advanced.

## Other tools

Brevo, MailerLite and Mailchimp let you paste the HTML into their code editor and save it as a reusable template.
